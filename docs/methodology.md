# 数据口径与限制

## 检索与样本

总命中数来自 PubMed ESearch 的 `count`；分析样本是按 `maxRecords` 拉取并解析成功的摘要元数据。两者在 UI 中分开显示。PubMed 请求集中在后端，浏览器不会携带 NCBI 凭据。

## 年份与地域

年份依次尝试电子出版日期、期刊正式出版日期与 MedlineDate 中可解析的年份。地域取第一作者第一条 affiliation，并使用维护中的国家/地区字符串映射做启发式解析。未识别项保留为“未知”，不能被解读为“没有该国家”。

## 引用与开放获取

引用数来自 Europe PMC 的开放 `citedByCount`。近五年榜单按 `ln(1 + citationCount) / sqrt(max(ageInYears, 1))` 排序；缺失引用是“暂无数据”，而不是 0。开放获取优先识别 PMCID/Europe PMC。系统不集成 Sci-Hub，不代理未知 PDF，也不会把未查到合法版本写成确定付费。

## 主题与报告

关键词是标题双权重、摘要单权重的轻量词频；MeSH 单独统计。主题卡片是可解释的规则归纳，不等同于人工编码或机器学习评估结果。默认中文报告为规则生成，每条结论附带本次样本中的 PMID；没有 LLM key 也可运行。
